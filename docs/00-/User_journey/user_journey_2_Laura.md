
## User Journey de Laura - Proxxi & Développeuse

| Étape clé | Objectif utilisateur | Actions / points de contact | Émotions | Freins / Opportunités |
|---|---|---|---|---|
| Préparation du rendez-vous | Retrouver les infos du collaborateur | Ouvre l'app, consulte la fiche depuis son mobile | Rassurée si rapide | Frein : infos éparpillées → Fiche unifiée |
| Vérification des rappels | Ne pas oublier les 3 RDV annuels | Consulte les notifications et rappels automatiques | Sereine si bien alertée | Frein : oublis fréquents → Push proactif |
| Saisie du compte rendu | Centraliser les échanges | Remplit le formulaire mobile après le RDV | Frustrée si trop long | Frein : formulaire trop complexe → Saisie rapide |
| Suivi prioritaire | Repérer les collaborateurs à risque | Accède à la liste de ses 8 suivis, filtre par priorité | Efficace et rassurée | Frein : vue peu lisible → Tableau clair |

**Résumé**

Laura consulte l'app en mobilité, souvent entre deux rendez-vous. Elle a besoin d'une interface rapide et mobile-first pour ne jamais perdre le fil de ses 8 collaborateurs.
