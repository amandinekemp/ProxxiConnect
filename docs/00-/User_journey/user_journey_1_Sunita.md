## User Journey de Sunita - Responsable suivi collaborateurs

| Étape clé | Objectif utilisateur | Actions / points de contact | Émotions | Freins / Opportunités |
|---|---|---|---|---|
| Connexion au dashboard | Accéder à une vue globale rapide des collaborateurs | Ouvre l'app, consulte le tableau de bord central | Soulagée | Frein : données encore dispersées → Centralisation |
| Détection des alertes | Identifier les situations à risque | Filtre les alertes, clique sur un collaborateur | Préoccupée mais rassurée | Frein : alertes peu visibles → Codes couleur |
| Analyse des statistiques | Suivre les stats des Proxxi | Consulte les graphiques, filtre par période | Concentrée | Frein : export manuel chronophage → Export auto |
| Reporting semestriel | Préparer les 2 réunions clés | Génère le rapport, vérifie les primes, exporte le bilan | Satisfaite si gain de temps | Frein : données incomplètes → Rapport automatisé |

**Résumé**

Sunita a besoin d'une vue claire, centralisée et rapide pour piloter le dispositif Proxxi. Elle gagne en efficacité si l'outil automatise le reporting et met en évidence les alertes.
