**Persona ProxxiConnect \#2 :**   
**Laura, Proxxi**

**Nom :** Laura Bernard  
**Âge :** 31 ans  
**Profession :**   
Proxxi et Développeuse  
**Situation personnelle :**   
En couple

Laura est développeuse et est Proxxi de 8 collaborateurs en mission chez différents clients. Elle échange régulièrement avec eux afin de garder une proximité avec l’entreprise, détecter les éventuelles difficultés et maintenir un suivi humain.

Ses journées sont très mobiles : rendez-vous client, déplacements, échanges Teams et appels téléphoniques. Elle a besoin d’un outil rapide à utiliser depuis son téléphone ou son ordinateur portable.

Objectifs avec ProxxiConnect

* Retrouver rapidement les collaborateurs qu’elle suit ;  
* Saisir facilement les comptes rendus après les rendez-vous ;  
* Recevoir des rappels automatiques ;  
* Suivre les collaborateurs nécessitant une attention particulière ;  
* Respecter les obligations liées aux 3 rendez-vous annuels.

Motivations

* Maintenir une bonne relation avec les collaborateurs ;  
* Ne pas oublier les suivis ;  
* Centraliser les informations importantes.

Frustrations et freins

* Oublier certains suivis ;  
* Perdre des informations dans les mails ou notes personnelles ;  
* Multiplier les outils.

Usage type

* Consulte l’application après un rendez-vous ;  
* Remplit les questionnaires depuis son téléphone ;  
* Vérifie les rappels de suivi ;  
* Consulte les informations d’un collaborateur avant un échange.

Citation typique

"Je veux pouvoir faire mon suivi rapidement sans perdre de temps."

Niveau digital
